# Gravweb V1 Hello World

Esta es una aplicacion minima React + Vite para la Plataforma Gravitacional.
Su proposito es validar el ciclo bidireccional entre la herramienta web, GitHub y Codex sin agregar complejidad innecesaria.

## Instrucciones de uso local
1. Instalar dependencias: `npm install`
2. Iniciar servidor de desarrollo: `npm run dev`
3. Construir para produccion: `npm run build`
